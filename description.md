# Description

WP-ChatGTP Site Audit API is a private WordPress REST API plugin for structured auditing, inspection, and controlled rebuild workflows.

Designed for developers, agencies , and anyone inheriting ageing WordPress installs held together by optimism and expired plugins.

The plugin exposes clean audit endpoints for:

* site summaries
* page inventories
* theme inspection
* structured content analysis

Rather than scraping wp-admin screens or manually spelunking through templates, TABARC converts WordPress into something closer to a queryable system..

Built if im honest a cynical philosophy:

* no unsafe live file editing
* no arbitrary code execution
* no “AI magic vibe ,rebuild” nonsense
* no production self-destruction features pretending to be innovation

Current focus is on audit infrastructure and rebuild intelligence.

Future development aims include:

* accessibility analysis
* design system extraction
* classic → block theme migration tooling
* SEO structure audits
* media and template analysis
* AI-assisted rebuild pipelines with human review

This plugin exists because large WordPress sites rarely fail from lack of features.

They fail from entropy. And stupidity and bad updates....
